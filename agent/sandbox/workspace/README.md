# Pre-research workspace

This directory is seeded into `/workspace` at session start.

Create per-run scratch pads at:

```
/workspace/pre-research/<video_id>/<run_id>/
```

Copy schema notes from `$HOME/.agents/skills/pre-research-schema/references/postgres-schema.md` if you need them on disk.

Do not store secrets here. Do not write raw transcripts into intent files.
